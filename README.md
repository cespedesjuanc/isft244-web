# ISFT N°244 · Sitio web

Landing page del Instituto Superior de Formación Técnica N°244 de Marcos Paz, provincia de Buenos Aires.

Sitio estático (HTML, CSS y JavaScript, sin dependencias ni build). Para publicarlo, subí el contenido de esta carpeta a la raíz del hosting.

## Estructura

- `index.html`: la página
- `css/estilos.css`: estilos
- `js/main.js`: menú, animaciones y red de datos animada
- `fonts/`: tipografía Archivo (licencia SIL Open Font, ver `fonts/OFL.txt`)
- `img/`: logo del instituto

## Ver en local

Abrí una terminal en esta carpeta y ejecutá `python -m http.server`, luego entrá a http://localhost:8000. Abrir `index.html` con doble clic funciona, pero algunos navegadores no cargan la tipografía desde archivos locales.
